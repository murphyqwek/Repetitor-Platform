# Frontend

Next.js App Router, React и TypeScript. Вход и регистрация подключены к существующему Java identity-service. Токены остаются в HttpOnly cookies; фронтенд получает CSRF-токен перед изменяющими запросами.

## Запуск

Требуется Node.js 20.9+ и работающий identity-service (по умолчанию http://localhost:8080).

```powershell
cd frontend
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Открыть http://localhost:3000. `IDENTITY_API_URL` задаёт адрес backend на стороне Next.js; браузер обращается к одному origin через `/api`. Для локального HTTP backend должен работать с `identity.security.cookies.secure=false` (dev-профиль). В production cookies должны быть Secure и сайт должен работать по HTTPS.

## Страницы

- `/login`: общий вход по логину для всех ролей, показ пароля, ошибки и подсказка для учеников.
- `/register`: регистрация родителя по 12-символьному коду преподавателя.
- `/register/teacher/{code}`: регистрация преподавателя после проверки ссылки администратора.
- `/profile/complete`: обязательное заполнение имени и фамилии после регистрации; отчество необязательно.
- `/account`: минимальный экран подтверждения входа с профилем и выходом. Полный кабинет в этот этап не входит.
- `/terms`, `/privacy`: явные заглушки документов по согласованию. Перед реальной эксплуатацией заменить документами и обновить `NEXT_PUBLIC_POLICY_VERSION`, `NEXT_PUBLIC_TERMS_URL`, `NEXT_PUBLIC_PRIVACY_URL`.

Ученики не регистрируются самостоятельно: данные выдаёт родитель после одобрения заявки. Преподавателям не предлагается открытая регистрация без приглашения. Пароль подтверждается на клиенте; в API передаётся один пароль. Восстановление пароля в backend отсутствует, поэтому форма не показывает неработающую ссылку сброса.

## Проверки

```powershell
npm test
npm run typecheck
npm run build
npm start
```

Тесты проверяют клиентскую валидацию, согласие, передачу кода преподавателя, ошибки API, CSRF, cookies, обновление сессии и переход к заполнению ФИО. Серверные права и валидация остаются ответственностью identity-service.

## Визуальное направление

Спокойный розовый акцент, светлые поверхности, Manrope, без игрового и пиксельного декора. Оригинальная иллюстрация тетради выполнена в CSS/SVG. В качестве композиционных ориентиров просмотрены формы https://linear.app/login и https://app.notion.com/login; чужие изображения, код и брендинг не копируются.
