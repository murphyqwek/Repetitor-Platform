# Локальный запуск Docker

Нужны PowerShell 7 и Docker Compose 2.20+ с Linux-контейнерами. Из корня проекта выполните:

```powershell
pwsh -File ./start-local.ps1
```

Скрипт при первом запуске создаёт `.env` и пару JWT-ключей в `.local-docker`, затем запускает Next.js, Identity, Education, Assignment и их инфраструктуру. Откройте [платформу](http://localhost:8090). API сервисов доступны на портах 8080, 8081 и 8082 соответственно.

При существующем `.env` сохраняйте пароли уже инициализированных БД и MinIO. Если каких-то переменных не хватает, сверяйтесь с `.env.example`. JWT внутри Docker подписываются ключом из `.local-docker`. При переходе с отдельно запущенного Identity войдите заново.

Для проверки состояния и остановки используйте `docker compose ps -a` и `docker compose down`. Данные остаются в именованных томах. Все образы приложений собираются из корневого `Dockerfile`.
