# Online Lesson Service — модель PostgreSQL и MongoDB

11 основных SQL таблиц, 3 Mongo коллекции. Типы: UUID серверные, instant `timestamptz`, UTC API, original_date в Europe/Moscow. Все поля NOT NULL кроме обозначенных `?`. FK только локальные. CHECK для enum, неотрицательных размеров/счётчиков, корректных временных интервалов. Flyway, ddl-auto=validate. Имена могут адаптироваться к conventions без изменения семантики.

## 1. PostgreSQL
### 1. online_lesson
`id uuid PK`, `course_id uuid`, `course_title text`, `teacher_id uuid`, `lesson_type text SINGLE|RECURRING`, `single_lesson_id uuid?`, `series_id uuid?`, `original_date date?`, `status text STARTING|ACTIVE|FINISHING|COMPLETED|START_FAILED`, `scheduled_starts_at/ends_at timestamptz`, `actual_starts_at/ends_at timestamptz?`, `teacher_absent_since timestamptz?`, `finish_reason text?`, `media_status text PROVISIONING|AVAILABLE|UNAVAILABLE|CLOSING|CLOSED`, `media_generation int default 0`, `students_can_draw/chat bool default true`, `created_at timestamptz`, `start_deadline_at timestamptz`, `guard_released_at timestamptz?`, `compensation_completed_at timestamptz?`, `aggregate_sequence bigint default 0`, `failure_code text?`, `state_revision bigint default 0`.
CHECK mutually exclusive SINGLE vs RECURRING columns, scheduled end > start, actual end >= start, actual start present ACTIVE/FINISHING/COMPLETED, actual end present FINISHING/COMPLETED, START_FAILED no actual start. Hard deadline derived actual start +6h. Partial unique (teacher_id) WHERE status IN STARTING,ACTIVE; partial unique (single_lesson_id) and (series_id,original_date) WHERE status <> START_FAILED OR compensation_completed_at IS NULL (including completed successful lesson). Start failed compensation release required before retry. History index (teacher_id,actual_starts_at DESC,id DESC), course equivalent, active deadline/absence scan partial. Guard ID = attempt lessonId. State revision monotonic.

### 2. lesson_participant
`id uuid PK`, `lesson_id FK`, `user_id uuid`, `display_name text`, `role STUDENT|TEACHER|ADMIN`, `assigned_at timestamptz`, `kicked bool default false`, `membership_revoked bool default false`, `identity_blocked bool default false`, `authorization_suspended bool default false`, `can_draw/can_chat/can_publish_camera/can_publish_microphone/can_share_screen bool`, `cursor_color text`, `identity_verified_at/education_verified_at timestamptz?`, `access_revision bigint`, `admin_slot_active bool default false`, `first_joined_at/last_left_at timestamptz?`, `presence_seconds/unknown_seconds/connection_count bigint default 0`, `eligibility_ended_at timestamptz?`. UNIQUE(lesson_id,user_id); unique partial (lesson_id) WHERE role=ADMIN AND admin_slot_active; exactly one owner teacher via partial unique role TEACHER and application owner invariant. Current access derived: ACTIVE, valid freshness, no flags, current assignment, permission. Historical assigned rows persist even after exclusion; at most 8 simultaneously eligible students under lesson lock. Restore does not remove unrelated flags. Current admin slot reserved before token/APP join, expires if neither confirmed within 60s; release under lock when no active channel, unknown media handled conservatively. Cursor palette stable per participant. Index user_id,lesson_id; lesson_id,role. Store source versions if supplied (`identity_source_version/education_source_version bigint?`); delayed events reconcile current truth, no stale grants.

### 3. participant_connection
`id uuid PK`, `participant_id FK`, `kind MEDIA|APP`, `external_session_id text`, `media_room_id uuid? FK lesson_media_room`, `connected_at timestamptz`, `last_confirmed_at timestamptz`, `disconnected_at timestamptz?`, `status PRESENT|ABSENT|UNKNOWN`, `disconnect_reason text?`. Unique external identity scoped by room for MEDIA, APP session globally unique; partial unique (participant_id,kind) WHERE disconnected_at IS NULL. Late event old SID/generation cannot close new connection. Check kind→room nullability. Last observation vs logical closure explicitly separated. Retain until finalization/cleanup; use current presence projection under participant lock.

### 4. attendance_interval
`id uuid PK`, `participant_id FK`, `kind PRESENT|UNKNOWN`, `started_at timestamptz`, `ended_at timestamptz?`, `boundary_source text`, `estimated bool`. CHECK end>=start. Partial unique participant_id WHERE ended_at IS NULL; intervals disjoint by lane/SQL participant lock (optional exclusion constraint). ABSENT implicit gaps. Bound intervals by actual start/end and assignedAt; close when no allowed connection. Count contiguous PRESENT intervals as connection_count (not raw transport reconnects); unknown duration separate. First/last reflect PRESENT observation, confidence disclosed. Store durable intervals before cleanup. Index (participant_id,started_at). No double counting across channels.

### 5. lesson_media_room
`id uuid PK`, `lesson_id FK`, `generation int`, `room_name text`, `room_sid text?`, `state PROVISIONING|AVAILABLE|UNAVAILABLE|CLOSING|CLOSED`, `created_at timestamptz`, `closed_at timestamptz?`, `last_verified_at timestamptz?`, `error_code text?`. UNIQUE(lesson_id,generation), UNIQUE(room_name); room name lesson-{lessonId}-{generation}. Never reuse old generation even after server auto-close. Current pointer in online_lesson. History of rooms retained minimally until cleanup and 7d diagnostics; IDs never reused. Index state/lesson. No JWT.

### 6. lesson_chat_message
`id uuid PK`, `lesson_id FK`, `author_id uuid`, `author_display_name text`, `author_role text`, `client_message_id uuid`, `payload_hash text`, `text text`, `created_at timestamptz`, `deleted_at timestamptz?`. UNIQUE(lesson_id,author_id,client_message_id). Text 1..4000 nonblank. Index `(lesson_id,created_at DESC,id DESC) WHERE deleted_at IS NULL`. Deleted row receipt remains until lesson cleanup; text can be scrubbed if hash remains and schema accommodates it (default retain until cleanup).

### 7. lesson_file
`id uuid PK`, `lesson_id FK`, `uploaded_by uuid`, `file_name text`, `object_key text UNIQUE`, `mime_type text`, `size_bytes bigint`, `content_hash text`, `state UPLOADING|READY|DELETING`, `created_at timestamptz`, `upload_lease_token uuid?`, `upload_deadline_at timestamptz?`, `width/height int`, `last_error_code text?`. Unique partial (lesson_id,content_hash) WHERE state IN UPLOADING,READY; concurrent duplicate returns existing READY or pending/conflict, no duplicate quota. Reserve size/count incl UPLOADING under lesson lock, max concurrent uploads 3 per uploader; enforce actual bytes/hash/signature/dimensions before READY. Unique immutable key generated before PUT; no key reuse. All file states count toward physical quota until confirmed delete. Index lesson_id,state; deadline scan. READY only ACTIVE + current lease. Cleanup scans own namespace and removes orphan keys after grace, not in-flight metadata; late PUT fenced from publication, reconciliation repeated.

### 8. livekit_webhook_event
`event_id text PK`, `event_type text`, `room_name text?`, `participant_sid text?`, `occurred_at timestamptz?`, `received_at timestamptz`, `payload jsonb`, `state PENDING|PROCESSED|FAILED`, `processed_at timestamptz?`, `next_attempt_at timestamptz`, `attempts int`, `error_code text?`. Verified before insert. No token/track content. Process under lane; old generation/SID ignored. Retention payload 7d after success; durable compact dedup key or state/version fence for older events (keep ID tombstone for MVP). Never delete unprocessed due to age.

### 9. outbox_event
`event_id uuid PK`, `aggregate_id uuid`, `aggregate_sequence bigint`, `event_type text`, `event_version int`, `payload jsonb`, `correlation_id uuid`, `occurred_at timestamptz`, `state PENDING|PROCESSING|PUBLISHED`, `next_attempt_at timestamptz`, `attempts int`, `lease_until timestamptz?`, `lease_token uuid?`, `published_at timestamptz?`, `error_code text?`. UNIQUE(aggregate_id,aggregate_sequence), eligibility index state/next_attempt; earliest unpublished aggregate first. 7d published retention, never reset aggregate sequence.

### 10. inbox_event
`event_id uuid PK`, `producer text`, `event_type text`, `aggregate_id text`, `aggregate_sequence bigint?`, `received_at timestamptz`, `processed_at timestamptz?`, `payload_hash text`, `payload jsonb?`. Insert+local rights/job effect atomic; commit before offset ACK. Retain ID/hash indefinitely MVP (compact tombstone), remove payload after 7d; old/replayed events never restore obsolete privileges. Poison message operational alert, controlled quarantine/retry without silent loss.

### 11. lesson_job
`id uuid PK`, `lesson_id FK`, `type START_LESSON|PROVISION_MEDIA|ROTATE_MEDIA_ROOM|CLOSE_MEDIA_ROOM|RELEASE_SCHEDULE_GUARD|CLEANUP_LESSON|CLEANUP_FILE`, `dedup_key text UNIQUE`, `payload jsonb`, `state PENDING|PROCESSING|DONE`, `step text?`, `attempts int`, `next_attempt_at timestamptz`, `lease_until timestamptz?`, `lease_token uuid?`, `last_error_code text?`, `created_at timestamptz`, `done_at timestamptz?`. Poll eligible PENDING or expired PROCESSING FOR UPDATE SKIP LOCKED; lease/token compare for completion. Stable keys by lesson/type/generation/file. Durable step checkpoints; no external I/O under SQL lock. Retry capped backoff/jitter, alert aged backlog. Retention DONE 7d only if durable terminal state prevents recreation/late results; do not delete incomplete jobs.

## 2. MongoDB
Replica set; transactions with majority write concern, retry transient transaction/unknown commit (resolve receipt before ACK). UUID encoded consistently. No public Mongo endpoint. Collections:
- `boards`: `_id=boardId`, `lessonId` unique, `revision` long, ordered `pages:[{pageId,title}]`, `createdAt`. One document per lesson. Index unique lessonId.
- `board_pages`: `_id=pageId`, `boardId`, `lessonId`, `revision` long, `epoch` long, `background` typed object, `elements` map keyed by safe validated ID, entries `{serverVersion,createdBy,updatedBy,locked,deleted,data}`. Unique (boardId,pageId) and lessonId index; `_id` uniqueness suffices for globally unique pageId. Element ID restricted safe chars (no dots/$ or operator injection). Preserve order via explicit ordered IDs or validated Excalidraw ordering indices; bindings/group references validated final scene. Max 5000 active elements, actual serialized BSON ≤8 MiB incl tombstones. Delete retains tombstone (version increments); restore only conditional. Clear epoch++, revision++, empty map; no resurrect old epoch. Background metadata independent of regular objects, locked PDF background as server-controlled object/reference.
- `board_operation_receipts`: `_id`, lessonId, actorId, operationId, pageId, hash, acceptedRevision, epoch, compact result (element versions/IDs), createdAt. Unique (lessonId,actorId,operationId), index lessonId. Same Mongo transaction as accepted page/metadata mutation. Store compact result not full scene, repeated payload returns prior ACK; changed payload conflict. Retain all receipts until finish, including clear epochs. No TTL as primary cleanup. Bounded receipt storage: technical default max 500k accepted durable commands per lesson, configurable; reject OVERLOADED before exceeding, validate under max scenario in PoC.

Page add/delete/reorder updates board metadata and page docs atomically in Mongo txn. All mutations use lane and compare revisions for CAS. Snapshot is one document consistent read; metadata revision used for structure conflicts. Background and focus semantics in WS contract. Cleanup deletes by lessonId (idempotent), no physical late recreation; stale pending steps checked and reconcile after ambiguous remote outcome. Cross-store file references require READY/lesson match at application layer, no Mongo→SQL FK. Do not delete files individually until end.
